# C12 small forms contract

The 111 cases cover unary operations, bitwise and shift effects, patterns, ranges, and iterator `any`. `cases.json` pins each source, fixture and fuel. The contract runs stock and fresh in separate bounded children and compares their observations, including values, aliases, event order, post-state, cleanup, typed errors and reuse. It retains the raw child output in the run directory.

Cross-engine comparisons omit the private `raw` error envelope. `p1_counts.json` limits function-name pointer normalization to the declared paths. Reviewed diagnostic differences are source-bound and compare a hash of the live stock projection with the retained ruling; the fresh expectation remains a literal. The fuel row retains its reviewed resource policy. Two former capturing-predicate refusals are admitted as stock-exact; the byte-string refusal remains explicit.

Set a new absolute `C12_OUT` and run `small_forms::contract` with `--ignored --exact --nocapture --test-threads=1`. Each child has CPU, address-space, file-size, output and wall limits. The contract checks executor idleness, balanced store entries and payload bytes, and reuse on the same executor and store.
