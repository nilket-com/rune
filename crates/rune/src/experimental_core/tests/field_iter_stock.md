# Stock field and iteration contract

228 source cases generated by gap_hunt/field_iter.rs, observed on fork
0d73d5b4 with test-only changes. These Rune-authored cases use the repository's
MIT OR Apache-2.0 license. The fixture retains source, phase, explicit error
class, exact message/value, stdout and stderr (hex encoded).

25 receivers x (2 fields x get/set/compound + iteration), 27 printed operand
order/failure witnesses, 25 mutation/lease/lifecycle cases, and one overflow case. Empty tuple is
Unit. Type and Bytes, tuple structs and unit structs are included in stock.
Execution has exactly 21 explicitly asserted coverage refusals: seven Bytes rows
(ByteStr) and seven each tuple/unit struct rows (UnresolvedFunction). These
are coverage gaps, not semantic convergence or new admission work. All 207
admitted rows must match stock exactly once S-field lands.

Three-key Object iteration observes a key-indexed accumulator and count in
Rune source. No sorting or text normalization is applied by the harness, and
no iteration order is promised. Other successful Object iteration rows have
one key, so their exact value/streams are deterministic.

Key findings:
- Heap non-record field reads/compound fail with UnsupportedObjectSlotIndexGet;
  set uses UnsupportedObjectSlotIndexSet. Explicit enum arms classify both as
  Type. Inline field-set missing fields are IndexOutOfBounds; field gets follow their
  own frozen rows. AccessError is classified
  as AccessConflict explicitly; raw text is unchanged.
- Object, Tuple and Vec iteration refuse mutation while their reader lease is
  active. Break/return/nested-break release Object leases.
- Option iteration takes a shallow payload snapshot with no lease on the
  wrapper. Replacing the wrapper or its payload succeeds; the yielded old
  heap payload is shared. None yields nothing, including when its unreachable
  body would mutate it. Snapshot ownership is tested across break, return and
  body errors; implementation fault injection separately checks heap cleanup.
